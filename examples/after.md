# Set up the backup tool

This guide shows you how to set up the backup tool before its first run. It takes about five minutes.

## Before you start
**Note:** The default backup folder may be wrong on your computer. Check it in step 2.

## Steps
1. Open the file `settings.txt`.
2. Find the line that starts with `folder=` and type the folder where you want your backups.
3. Save the file.
4. Run the backup tool.

## If something goes wrong
If your files are not where you expect, repeat step 2 and check the folder name.
